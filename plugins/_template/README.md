# _template

Starter scaffold for a new plugin. **Don't install this directly** — it isn't
listed in `marketplace.json`, so it stays an inert template.

To start a new plugin, see [`CONTRIBUTING.md`](../../CONTRIBUTING.md). The short
version: copy this folder to `plugins/<your-plugin>/`, edit `plugin.json`, keep
the components you need (`commands/`, `skills/`, `agents/`, `hooks/`, `.mcp.json`),
delete the rest, then add one entry to `.claude-plugin/marketplace.json`.
