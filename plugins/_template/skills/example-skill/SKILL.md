# Example skill

Everything here is instructions Claude follows when the skill triggers. Unlike a
command (which the user invokes explicitly with a slash), a skill is pulled in
automatically when the `description` above matches what's being asked.

Use a skill for reusable know-how / workflows; use a command for an explicit
"do this now" action. A plugin can ship either, both, or neither.

Delete this folder if your plugin doesn't need a skill.
